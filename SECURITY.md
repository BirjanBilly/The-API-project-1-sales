# Security and Responsible Data Use

1. Revoke any key pasted into chat, email, screenshots or source code.
2. Store replacement keys only in `.env` locally or a secret manager in production.
3. Never commit `.env`.
4. Collect public business information only.
5. Do not infer or generate personal phone numbers or emails.
6. A decision-maker is unverified unless a public source explicitly supports name and title.
7. Do not bypass CAPTCHA, login, access controls, rate limits or site restrictions.
8. Review GAF's current terms before automated collection and prefer an approved/licensed source in production.
9. Do not auto-send outreach from this prototype.
10. Add tenant isolation, RBAC, audit logs and encryption before production use.
